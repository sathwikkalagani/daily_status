## What I Learned 
- A C program generally consists of documentation, preprocessor/link section, definition section, global declarations, function prototypes, `main()`, and user-defined functions.
- C has 32 classic keywords.
- Data types specify the type of data a variable can store.
- Operator precedence determines the order in which operators are evaluated.
- System calls provide an interface between user programs and the kernel.
- File management system calls are used to open, read, write, reposition, inspect, duplicate, and close file descriptors.
- A process is a program in execution.
- PCB stores information required by the kernel to manage a process.
- Process Address Space contains Text, Data, BSS, Heap, and Stack.
