## What I Learned
- malloc() dynamically allocates a specified number of bytes and leaves the memory uninitialized
- calloc() allocates memory for a specified number of elements and initializes it to zero
- realloc() is used to resize previously allocated memory
- free() deallocates dynamically allocated memory
- Forgetting to free dynamically allocated memory can cause a memory leak
- Pointer variables and dynamically allocated memory can be stored in different memory areas
